\# SLIC Vehicle OCR Frontend



React + Vite + TypeScript frontend for the \*\*Vehicle CR Smart OCR middleware\*\*.

Uploads vehicle registration documents (images / PDFs) to the backend API,

which returns a quality assessment and OCR result via Gemini Vision.



\## Tech Stack



\- \*\*React 18\*\* — UI

\- \*\*TypeScript\*\* — type safety

\- \*\*Vite\*\* — build tool + dev server

\- \*\*Fetch API\*\* — backend communication



\## Requirements



\- Node.js 18+

\- npm 9+
